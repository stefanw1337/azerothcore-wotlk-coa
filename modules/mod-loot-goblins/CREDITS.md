# Credits

- **Loot beams** — the look of our beams (a soft, camera-facing shaft that fades in above the drop, a whiter core,
  colour by item quality) follows **wxl-loot-beam** by manatactical: https://github.com/manatactical/wxl-loot-beam
  (GPL-3.0, a WarcraftXL module). Our beam is a separate model made by our own generator; no code from that
  project is included.
- **Diablo III** — the Treasure Goblins, Greed, the gold heap and the item ground models ("flippies") are
  Blizzard Entertainment's. They are not part of this repository: the setup tools download them from Blizzard's
  CDN and convert them on each player's PC.
- **CoA64** (ilusixn) — the 64-bit client the forced nameplates were added to.
